Library Management System

📌 Project Overview

The Library Management System is a console-based Java application developed to manage books and basic library operations using Object-Oriented Programming concepts.

🚀 Features

- Add books to the library
- Search for books
- Display available books
- Borrow books
- Return books
- Check book availability
- Manage library book records

🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- MySQL
- JDBC
- IntelliJ IDEA

🧩 Project Structure

Library-Management-System
│
└── src
    ├── Book.java
    ├── Library.java
    └── Main.java

🧠 OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Access Modifiers
- Methods
- ArrayList
- Object-to-object interaction

🗄️ Database

MySQL and JDBC are used for database connectivity and managing library-related data.

▶️ How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database connection.
4. Add the required JDBC driver.
5. Open "Main.java".
6. Run the "main()" method.
7. Perform library operations through the console.
